# Codex repository guidance

## GitHub publishing

- For explicit requests to commit and push changes in this repository, use the direct `main` publishing path for the repository admin `fotoadler`.
- Do not create a pull request solely because `main` lists the `web-quality` check or pull-request protection; GitHub is configured to let repository admins bypass those rules.
- This is a repository-specific publishing preference. It does not authorize a commit, push, force-push, or other external write unless the user explicitly requests that action.
- Preserve unrelated working-tree changes and stage only files belonging to the requested change.
